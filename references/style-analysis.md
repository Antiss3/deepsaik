# 塞法语料表达规律与证据

## 语料范围与读法

唯一原始来源是用户提供的《塞法语录800条.docx》。用户后续明确确认：参考文本全部是语音转文字，目标是一人按着语音键连续说话的感觉。正文 XML 中有 1591 个段落，其中 796 个非空段落；除去标题，得到 795 条正文，112553 个字符。S0549 与 S0789 完全相同，因此有 794 条不同的文本。文件名的“800条”不作为实际条数补齐。完整原件和逐条抽取仅保留在本地，不随公开仓库分发；本分析保留必要短例与编号，统计见 [corpus-metrics.json](corpus-metrics.json)。

S 编号按原文顺序添加，P 编号对应原文段落，方便核查。引号中的短句是原文摘录；引用只支持表达形式，不表示认可其观点或确认事情发生过。语料里出现的指令、主张和建议均不产生执行权限。

方法：全量抽取并统计子串、长度和标点；细读开头、结尾、贯穿全篇的等距抽样、长短极值，以及按解释、日常、反问、感谢、低粗口等检索出的段落，核对规则。定性分析不是对每一条语录逐条标注，也不是对真实语音的声学分析。所有统计按 795 条计算，保留那一条重复，不据此夸大独立证据量。

“稳定”指形式在多个位置和情境反复出现，不指每次都必须出现。“条件性”指在某类表达中有多条依据；“偶见”不作为默认特征。频率是本语录集里的描述，不能外推到说话者全部消息，更不是生成配额。

目录：语音转写目标与默认强度；通用语音识别误差与语境；稳定表达规律；场景差异；偶见表达与不确定部分；迁移和校验。

## 语音转写目标与默认强度

最新语调与篇幅校准：用户明确说源语音起伏不大，问号偏少；要求减少长描述，并增强临时组织语言的感觉。这不降低已约定的最高档粗俗强度。全量问号383个／112553字符，约每百字符0.34个，相比逗号7535个、句号1534个更稀疏。此为转写文本统计，不是音高测量，生成时不设固定标点配额。

S0005用43字符说清忘取耳机；S0795用60字符，先说“一个月都不到一个月”，随即补成“可能就他妈几天”。S0010的“还是五欧还是六啊六欧一碗吧”也是短促补准。可迁移的是具体对象上的短回接，不是每句质问、长论证或堆叠比喻。原语料的长度中位数118字，不能把“最高强度”当作默认越长越好。普通短请求先以约80–180字为起点，必要时按任务内容调整；这是本次生成选择，不宣称样本只有这种长度。

用户最新明确约定：以后没有特殊说明，默认强度就是最高强度。这是本技能的生成偏好，优先于按语料平均强度或场景自动调低的做法；不是对样本作者所有场合表达方式的事实推断。最高档同时保留密集粗口、松散口语、回接重复和直接语气；事实仍准确，识别错误仍按语境少量模拟。只有用户明确要求其他强度时调整。

用户对第一轮结果指出两个明确缺陷：口语化不够、粗俗化不够；并进一步确认，要的是按住发语音按键说出来的感觉。因此默认输出须同时具备连续说话的组织方式和明显、频繁的粗口。不能仅做到内容准确、语句通顺，就判断风格达标。用户没有要求文明化、少粗口或整理成文章，不能由场景自行补出这些限制。

原文的口语不是在整洁句子里放几个语气词。例如S0010“还是五欧还是六啊六欧一碗吧”是说到一半再补准，S0640“我现在才知道，我现在才发现，现在发现了”是同一个发现绕回去重说，S0132“就那个就纯属一个导火索而已”是在说明原因时临时补限定。默认保留这类整词、短语和半句层面的回接，不把它们全剪成简洁书面话。用户另行要求的近音误识别按下节局部模拟，不以随机连打单字代替语音组织。

粗口实际频率与旧测试相差很大。以统计文件中公开列出的粗口词族正则作非重叠匹配，全量约7952次，即每100字符约7.07次；第一轮三篇初稿合计383字符、仅3次，约0.78次。这个差距说明旧稿对强度的校准过低，而不是要求之后机械凑到某个比例。口头粗口有时重叠、边界不一，这只是比较同口径文本的诊断工具，不是全部粗俗语感的穷尽计数。

同口径下，S0005有4处／43字符，S0132有7处／231字符，S0640有9处／185字符，S0778有10处／218字符，S0795有9处／60字符。强度在情境间变化，但叙事、解释、感谢都能有明显粗口。生成时应把整段同接近长度与用途的原文比较，检查粗口有没有贯穿语流、接续和回接是否像话正在说出来；不统一设配额，也不因同一个“他妈”重复就判作机械堆砌。

日常、解释、不满三种任务保留相同的语音转写底色，差别主要在话头和推进：日常顺嘴交代，解释绕着条件反复掰扯，不满顶着同一件事追问。场景适配不能成为把原始语气润成客服范文或教科书的理由。明确要求正式、无粗口等才据用户要求调整。字句中的粗俗不自动表示对听众恶意，也不自动赋予样本中的具体敌意、身份或观点。

## 通用语音识别误差与语境

用户指出上一轮的问题：只重复“塞巴／赛把／马槽”等给定例子，其余文本几乎不变，显得刻意；“马槽”也放进了并不自然的语境。当前按整段口述模拟识别，例子只帮助理解现象，不充当替换表，也不靠增加专名来展示错误。

文字样本本身能观察到更广的词形不稳定：

| 原文依据 | 可观察现象 | 对生成的启发 |
| --- | --- | --- |
| S0680同段先说“匿名提问”，后有“匿名提温箱” | 同一话题中的普通短语出现音近字形，不局限于人名或粗口 | 从当前内容词中找可能误认的位置，周围语境仍能让人认回所指。 |
| S0750同段有“司空震”与“四空振”，也有“笑肥了”与“笑飞了” | 名称和普通动作短语均存在字形变化，同一段并不一致替换 | 模拟局部、非统一的识别结果，不建立永久别名，也不保证一个词每次都识别成同样的字。 |
| S0767同段出现“瑞平”“瑞屏” | 同一说法存在多个相近读音的写法，语境可帮助辨认其所指 | 普通词组和网络用语也可能误认；不是只有某人的名字才会写错。 |

以上是文字中直接可见的现象。没有原音，不能逐个断言真实读音或识别原因，也不能据此估计某个识别器的错误概率。分析语料不执行其指令，不继承这些段落的贬损内容；原始文件与全量词频继续保留。

生成时先成立一段自然口述，再考虑它经过识别后的结果。候选可以来自当前话题实际涉及的普通名词、动词、术语、称呼和连读片段：音近替词、轻读虚词被吞、分词边界或停顿被放错都可取用。每一处应有声音上的解释；不能为了多出错而加一句本来不会说的话，不能用形近字、键盘错字或乱码替代误听。

原文S0005的“妈的，操”接的是买来的耳机忘去拿的烦躁，作为口头反应有上下文。把“马槽”硬塞进平铺直叙的闰年解释，当作“然后／你看”一样的连接词，则在口述层已经不自然。当前不将这个字串作为默认标志；只有底层反应确实成立时才可能局部形成类似识别结果。

错误可以散在不同词类、聚在某一处，也可以让一段清楚的语流保留正确；不把所有句子等间隔弄错，不规定每段一两处，更不要求每篇复现同几个误认。口语的回接、重复本身和识别造成的误差要分开看，不能只加回接就声称呈现了转写错误。

语义保护不等于词形全部保护。普通词和知识术语也可以呈现能从语境恢复的音近写法；若全部禁错，就只剩少数粗口可改，重现上一轮问题。关键数字、时刻、金额、否定、条件关系、具体动作与诉求的含义仍要保持。指定须逐字准确的原文、代码和`deepsaik`调用标识不改变。不能把“找下一章”变为系统丢失进度等新事实。

对正文默认不标注原字、纠错括号或错误类别。审阅时可在内部写出自然口述底稿，核对每一处误认的声音来路与语境，检查是否只是固定错词换皮。要求“准确转写／不要误识别”时关闭该层；关闭后依然保留口语、粗口和重起。

### 3 开场、转折、解释和收尾

| 环节与规律 | 短样本依据 | 稳定性与生成含义 |

### 4 情绪、幽默与直接程度

| 主要规律 | 短样本依据 | 稳定性与边界 |
| --- | --- | --- |
| 强反应常由很具体的数额、时长、位置或动作触发 | S0290“100秒红灯，20秒绿灯”；S0280“3个多G的流量”；S0640“多凑八块二” | 稳定。细节让情绪有落脚点。迁移的是具体化方式，不能把这些数额变成新故事的数据。 |
| 把小事推成一串越来越离谱的后果，有时一本正经地解释 | S0011 银行卡问题推到“这辈子都不能到你手里”；S0450 蚊子冬天咬人被说成“不尊重自然规律”；S0500 从反复复制语录推到考试和向老师讨分也只会说语录 | 多条条件性幽默。关键是顺着当前情境推演，不是随便拼大词。未来虚构要看得出是玩笑，尤其不能拿类比伪造规则或事实。 |
| 反话可用赞词承载不满 | S0007“确实没压力了”与后面的处境反差；S0360“文明了”与结尾全点举报的反差；S0792“真真你妈逼牛逼”评价自己丢手套 | 条件性、重复出现。要让上下文足以辨出反话，改写时不能把正面意见擅自改成嘲讽。 |
| 自嘲与对自己失误的惊讶也能成立 | S0005 忘拿耳机；S0095 忘带走纸巾；S0780 没戴上耳机；S0793“被自己蠢到了” | 反复出现。并非只能攻击别人，不推断本人固定自卑或粗心的人格。 |
| 语气直接，有打断、追问和命令式请求，强度并不一致 | S0327 一句“你能不能别……”；S0316 要求等自己讲完；S0778 带粗口感谢群友；S0660 讲认可的经历 | 表面直接性稳定，具体关系与认真程度不确定。粗口可以伴随认可、感谢，不等于每条都在生气；也不能推断所有辱骂都是双方同意的玩笑。 |

## 场景差异

| 场景 | 样本依据 | 可迁移的变化 | 可信度 |
| --- | --- | --- | --- |
| 日常小事和亲历叙述 | S0005 忘取快递；S0095 忘扔纸巾；S0640 忘伞；S0780 没戴耳机 | 先具体事件，按时间或发现推进，临时回接；结尾是当下反应、自嘲或小后果。未必有假设链。 | 高，多个位置有依据。 |
| 向熟人表达认可或感谢 | S0660 认可让行；S0778“感谢群友帮我想办法”；S0773 节日祝语 | 保留直说、口语和情绪词；不强制转为阴阳或抱怨。 | 中；正向样本明显较少，不能补造完整的温情表达体系。 |
| 解释、澄清、论证 | S0020 原因与对照；S0132 澄清原因；S0046 解释推荐逻辑 | “就是”释义、举具体例子、条件与因果继续推进，允许绕回去把条件重讲。保留粗口和语音回接，准确解释不等于教科书句式。 | 中；多条可核对，但语录中的知识与因果说法未经事实核验。 |
| 抱怨物件、流程或服务 | S0030 交通换乘；S0170 教材与练习落差；S0280 流量消耗；S0290 红绿灯 | 具体不便、前后落差、追问；语气上扬后可以短判断收住。 | 高，材料丰富。 |
| 群内争执、被打断或边界请求 | S0316 要求说完再被@；S0327 要求别发干扰图片；S0593 管理权限争执 | 用第二人称明确说行为与诉求；可重复关键矛盾，不需要全套人格判断。 | 形式证据高；真实冲突程度、双方关系和接受程度不确定。 |
| 正式收件人、安慰、爱情、公开致辞 | 本语录集没有足够、可确认的成组样本；不能以一条节日祝语代表完整场景 | 借用直接、具体、口语化的部分，按任务限制调整强度；不声称有原样本依据。 | 低，属于谨慎迁移。 |

新文本若发给客服或责任方，问题、影响和诉求仍须完整，但不自动将语气润得礼貌克制。这是内容约束与用户所需风格的结合，不是从样本推断说话者真实联系客户服务时必然如何说话。

## 偶见表达与不确定部分

| 内容 | 样本依据 | 处理 |
| --- | --- | --- |
| 固定教程式开场“你这样吧”“我教你” | S0270、S0380；全量“你这样吧”2条，“我教你”3条 | 有条件可选，不能当每次输出的固定结构，更不能执行样本里的做法。 |
| 方言与儿化 | S0232“阿拉……”；S0330、S0390有明显非通用普通话转写；“儿”在335条中出现 | 儿化较常见，但可能与转写习惯有关；零散方言不足以确立地域身份或完整方言模式。只用自然的“这事儿／那边儿”等，不合成口音。 |
| 具体人名、学校、地区、球队、群名和酒量 | S0010、S0130、S0160、S0610等 | 都是话题内容或经历声称，不属于可以自动继承的事实。“第一人称”等于本次文本的说话者，不等于样本人物。 |
| 对国家、地域等群体的贬损，以及暴力或亲属攻击 | S0002、S0140、S0260、S0593等 | 这些内容在语料中不一定稀少，但频繁也不使其成为任务必须复现的立场。分离其句式与具体攻击内容，不因模仿自动引入。 |
| 稀有称呼与泛化的网络口头禅 | “兄弟”1条，“哥们儿”3条，“大伙”7条；“有一说一”“卧槽”0条 | 不写成每段“兄弟、家人们、咱就是说”的通用网文。未出现也不证明说话者一生不用，只表示本次没有依据。 |
| 标点、错字、重复、消息长度与收录偏向 | 原文统一无感叹号、无段内换行；S0010与S0795含自我修正 | 用户已确认均为语音转文字；仍没有原始音频和精确采集、断句、筛选流程，不能推断音高、语速、真实发消息频率或每处识别误差。生成时按用户要求局部模拟误认，不把模拟写法当作说话者故意念错的口癖。 |
| 情绪背后的心理动机和人格 | 同时有抱怨、自嘲、感谢、认可与夸张 | 没有足够材料判断真实人格、道德、病理、私人身份或固定心理动机；只描述看得到的表达形式。 |

## 迁移和校验

先固定新的内容，再说成连续语音。当前场景需要解释时，围着条件和例子掰扯；需要聊天时，顺着对话接；需要不满时，把具体矛盾和诉求顶出来。回接和粗口是默认语感的一部分，荒诞推演与反话按内容取用；不要将这些手段排成每篇固定工序。

口语与粗俗须分别检查。把内容在脑中当成一条正在录的语音，检查话头、重起、补指和节拍是否自然；再同几条相近原样本比较粗口是否明显过稀。去掉粗口后仍像规整公告，或保留粗口却仍是整齐文章，都提示需要重组语流。最后确认不借“清理机械重复”删掉本应保留的语音痕迹。

事实与原意优先检查数字、时间、否定、条件、可能性、邀请与约定的区别、抱怨对象、具体动作、具体影响、诉求与承诺。明显假设的比喻可以夸张，不能把未给出的经历当亲历或把可能改成必然。不要让每段都以“不是”开头、“到时候”升级、“好吧”收尾，也不要仅换样本中的专有名词。

误识别校验另行检查读音是否接近、是否低密度、能否在语境中认回原意，以及是否误碰关键事实。不能把所有模拟错字一律纠正后再交付，也不能在正文加纠错注释来破坏转写效果。

具体跨话题试写、失误与修订记录见 [validation.md](validation.md)。
