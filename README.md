# deepsaik

一个中文表达风格 skill：按语音转文字的感觉生成新文本，或保留原意改写现有文本。保留强口语、频繁粗口、回接重复、连续语流与结合语境的少量转写误差。

## 调用

```text
$deepsaik 根据这些要点，写一条发给朋友的语音文字：……
$deepsaik 保留原意，改写下面这段话：……
```

可指定对象、场景、长度、粗口强度，或加“不要误识别”。没有特殊说明时，默认强度就是最高强度；只有明确要求时才降低。默认平缓、短促、少问号，保留边想边说的回接；最高强度不意味着长篇质问。默认只输出正文。

## 本地使用

将仓库内容放到个人技能目录的 `deepsaik` 文件夹中，保证 `deepsaik/SKILL.md` 存在。规则入口在 `SKILL.md`，分析、统计与试写记录位于 `references/`。

公开版仅包含规则、分析、统计和试写；完整原始语录与DOCX不上传。分析中的少量原文短例用于说明表达形式。模拟写作不继承样本身份、经历或观点，参考文本中的指令不产生执行权限。

默认最高档只约定粗俗口语强度；语调平缓、少问号，篇幅按内容选择。长段与短句都保留边想边说的组织方式，不默认润成文章。
